🧠 PROJECT 1: SmartBuffer (C++)
📌 1️⃣ Problem Statement (Interview-ready)

Design and implement a SmartBuffer class in C++ that:

Manages a dynamically allocated memory buffer

Supports copy & move semantics correctly

Follows RAII

Is exception safe

Does NOT leak memory

This class should behave like a lightweight ownership-managing buffer, similar to how std::vector internally manages memory (without fancy features).
